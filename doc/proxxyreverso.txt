Guia: Proxy Reverso com Terceiro Nginx (porta 8900)
Objetivo: Usar um nginx separado (fora do nginx do sistema) escutando na porta 8900,
fazendo proxy reverso para o Node.js na porta 8901. O Cloudflare (com proxy ligado)
recebe na porta 80/443 e encaminha para a 8900 do servidor.

Passo 1: Verificar portas
Antes de iniciar, confirme que as portas desejadas estão livres.

Bash:
ss -tlnp | grep -E ':(8900|8901|8902)'

Passo 2: Estrutura de diretórios
Bash:
mkdir -p /root/PEDIDOS/nginx/{sbin,conf,logs,run}

Passo 3: Copiar binário do nginx
Use o binário do nginx já existente no sistema (ex: /home/xui/bin/nginx/sbin/nginx).

Bash:
cp /home/xui/bin/nginx/sbin/nginx /root/PEDIDOS/nginx/sbin/
cp nginx/mime.types /root/PEDIDOS/nginx/conf/

Passo 4: Configuração do nginx
O arquivo de configuração está em nginx/terceiro-nginx.conf no repositório.
Deploy para o servidor em: /root/PEDIDOS/nginx/conf/nginx.conf

Configuração resumida:

server {
    listen 8900;
    server_name gestorpedidos.click www.gestorpedidos.click;

    location / {
        proxy_pass http://127.0.0.1:8901;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # Rate limit nas rotas de login
    location = /admin/login {
        limit_req zone=login burst=5 nodelay;
        proxy_pass http://127.0.0.1:8901;
        ...
    }
    location = /revenda/login { ... }
    location = /revenda/register { ... }
}

Passo 5: Iniciar o nginx
Bash:
# Iniciar
/root/PEDIDOS/nginx/sbin/nginx \
  -c /root/PEDIDOS/nginx/conf/nginx.conf \
  -p /root/PEDIDOS/nginx

# Ou usar o helper:
bash nginx/control.sh start

# Recarregar config após alteração:
bash nginx/control.sh reload

# Parar:
bash nginx/control.sh stop

Passo 6: Cloudflare
No painel da Cloudflare, configure o registro DNS:
- Tipo: A
- Nome: @ (ou www)
- Conteúdo: IP do servidor
- Proxy: Ligado (laranja)
- Origin Port: 8900

Com proxy ligado, o usuário acessa normalmente http://gestorpedidos.click
(Cloudflare recebe na porta 80/443 deles e encaminha para a 8900 do servidor).

Passo 7: Firewall
Libere apenas a porta do nginx (8900) no UFW:

Bash:
sudo ufw allow 8900/tcp comment 'Nginx PEDIDOS (Cloudflare proxy)'

As portas 8901 (Node) e 8902 (WhatsApp) escutam apenas em 127.0.0.1,
não precisam ser abertas no firewall.

Cloudflare Worker (URL Masking - opcional):
Se quiser que a raiz "/" mostre o login do revendedor sem mostrar "/revenda/login"
na URL, use um Worker Cloudflare:

export default {
  async fetch(request, env, ctx) {
    const url = new URL(request.url);
    if (url.pathname === "/") {
      const loginUrl = `${url.origin}/revenda/login`;
      return fetch(loginUrl, request);
    }
    return fetch(request);
  },
};

Configure a rota: gestorpedidos.click/*
